# Material Intelligence (材料インテリジェンス)

*[English](#english) | [日本語](#日本語)*

---

## English

A Claude-run pipeline that curates two things for a polymer / materials-chemistry
reader, on a weekly and daily cadence respectively, and renders them into one
combined page:

- **Paper digest (weekly)** — pulls new articles from ~24 polymer / materials
  journals (RSS for Nature/Wiley, Crossref for ACS/RSC/Elsevier), pre-filters by
  keyword, and has Claude score and rank the top picks against a tunable rubric.
- **Policy / market news (daily)** — a manually-triggered sweep of regulatory and
  market-trend sources for new-business scouting, framed around a target market
  and named bottlenecks.

Both tracks end by rendering a combined Markdown/HTML digest — a shared page with
reader-facing rating buttons that feed back into the scoring rubric over time.

### Repository layout

```
config/           scoring rubric, interest keywords, journal/news source lists
scripts/          fetch / triage / enrich / render / feedback-merge / Notion push
.claude/, .agents/  the operational runbook (skill) that drives the weekly/daily run
news/             news-track principles, curation rules, source list, templates
CLAUDE.md / AGENTS.md   full design + operational reference for the pipeline
```

Generated data (`data/`, `digests/`, `site/`, `feedback.md`, dated
`news/*_policy_news.*`) is not tracked in this repository — it is
reader/owner-specific output regenerated by the scripts and skill above.

### Environment

- Python 3 with `feedparser`, `requests`, `pyyaml`.
- Some scripts expect environment variables for optional integrations (e.g.
  `NOTION_TOKEN` / `NOTION_DB_ID` for the Notion push step). None of these are
  required to run the core fetch/triage/render pipeline.

### Workflow

See `CLAUDE.md` (design reference) and `.claude/skills/material-intel/SKILL.md`
(operational runbook) for the full weekly/daily procedure — tuning from reader
feedback, fetching, triaging, scoring, and rendering the combined page.

## 日本語

ポリマー・材料化学分野の読者向けに、**週次の論文ダイジェスト**と**日次の政策・市場
ニュースまとめ**をそれぞれ収集・選定し、1つの統合ページとして描画する、Claude 主導の
パイプライン。

- **論文ダイジェスト（週次）** — 約24誌のポリマー・材料系ジャーナル（Nature/Wiley は
  RSS、ACS/RSC/Elsevier は Crossref）から新着論文を取得し、キーワードで粗く絞り込んだ
  後、Claude が調整可能なルーブリックに沿ってスコアリング・ランキングする。
- **政策・市場ニュース（日次）** — 新規事業探索のため、規制動向・市場トレンドの情報源
  を手動トリガーで巡回する。対象市場とボトルネックを明示した基準で選定する。

どちらのトラックも最終的に統合された Markdown/HTML ダイジェストを描画する。読者が
評価ボタンで反応でき、その評価は時間とともにスコアリングのルーブリックへフィードバック
される。

### リポジトリ構成

```
config/           スコアリングのルーブリック、関心キーワード、ジャーナル/ニュース情報源
scripts/          取得・粗選別・エンリッチ・描画・フィードバック統合・Notion 連携
.claude/, .agents/  週次・日次の実行を駆動する運用手順（スキル）
news/             ニューストラックの方針・選定ルール・情報源一覧・テンプレート
CLAUDE.md / AGENTS.md   パイプライン全体の設計・運用リファレンス
```

生成物（`data/`、`digests/`、`site/`、`feedback.md`、日付付きの
`news/*_policy_news.*`）はこのリポジトリには含まれていない。これらは読者・所有者固有
の出力であり、上記のスクリプトとスキルによって再生成される。

### 環境

- Python 3、および `feedparser` / `requests` / `pyyaml`。
- 一部スクリプトは任意連携用の環境変数を想定（例: Notion 連携の `NOTION_TOKEN` /
  `NOTION_DB_ID`）。取得・粗選別・描画のコア部分の実行には不要。

### ワークフロー

週次・日次の全手順（読者フィードバックからのチューニング、取得、粗選別、スコアリン
グ、統合ページの描画）は `CLAUDE.md`（設計リファレンス）と
`.claude/skills/material-intel/SKILL.md`（運用手順）を参照。
